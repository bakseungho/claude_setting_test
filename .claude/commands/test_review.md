# 코드 리뷰

최근 변경 사항을 다음 기준으로 철저히 검토합니다.

## 1단계: 변경 사항 확인

`git diff --name-only HEAD~1`을 실행하여 변경된 파일 목록을 가져옵니다.

## 2단계: 각 파일 분석

각 변경된 파일에 대해 검토합니다:

### 코드 품질

- 함수가 단일 책임을 가지는지 확인
- 변수명과 함수명이 의도를 명확히 나타내는지 확인
- 복잡한 로직에 주석이 있는지 확인

### 타입 안전성 (TypeScript 프로젝트)

- `any` 타입 사용을 피했는지 확인
- 타입 단언(`as`)보다 타입 가드를 사용했는지 확인

### 성능

- O(n²) 이상의 복잡도를 가진 알고리즘이 없는지 확인
- 불필요한 반복 계산이 없는지 확인

### 보안

- 사용자 입력을 적절히 검증하는지 확인
- 민감 정보를 로그에 출력하지 않는지 확인

## 3단계: 결과 정리

발견된 모든 이슈를 다음 형식으로 정리합니다:

- [Critical]: 즉시 수정이 필요한 버그나 보안 취약점
- [High]: 중요하지만 즉각 배포를 막지 않는 문제
- [Medium]: 코드 품질 개선 사항
- [Low]: 권고 사항이나 스타일 이슈

이슈 목록을 `REVIEW_결과.md` 파일로 저장합니다.
