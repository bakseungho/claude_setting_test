# 브라우저 검증 규칙

## 검증이 필요한 작업

다음 작업 완료 후 반드시 브라우저로 검증한다:

- UI 컴포넌트 추가/수정
- API 엔드포인트 추가/수정
- 인증/권한 로직 변경
- 미들웨어 변경

## 검증 절차

Puppeteer MCP(`@modelcontextprotocol/server-puppeteer`)를 사용한다.

### 1. 페이지 접속

```
localhost:3000 접속 후 페이지 로드 완료 확인
```

### 2. 확인 항목

- **콘솔 오류**: 빨간 에러 메시지 없는지 확인
- **네트워크**: API 호출 실패(4xx, 5xx) 없는지 확인
- **UI 렌더링**: 변경된 컴포넌트가 의도대로 표시되는지 확인
- **기능 동작**: 수정한 기능의 핵심 시나리오(golden path) 직접 실행

### 3. 문제 발생 시

1. **스크린샷 캡처** — 오류 상태 기록
2. **콘솔 로그 수집** — 오류 메시지 전문 복사
3. **네트워크 탭 확인** — 실패한 요청의 요청/응답 본문 확인
4. **원인 파악 후 수정** — 추측으로 코드 변경 금지
5. **수정 후 재검증** — 동일한 절차 반복

## 검증 완료 기준

다음을 모두 만족해야 작업 완료로 간주한다:

- [ ] 콘솔에 에러 없음
- [ ] 변경된 기능이 정상 동작함
- [ ] 기존 기능에 회귀(regression) 없음
